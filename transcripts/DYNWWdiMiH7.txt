 The longer you continue a Claude Code session, the dumber it gets. And sometimes, compact is not enough to fix it. Compacting can still carry the shape of the previous conversation forward. Headends, messy debugging attempts, or bad assumptions are included. So what you actually want is a full handoff. Before you end a Claude Code session, tell it to create a handoff.md file. Have it include the goal, the current state, files it's currently working on, things that have changed, things it's tried that have failed, and what it's naming to do next. Then, run slash clear or start a new Claude Code session and tell it to read that handoff doc and continue from exactly where it left off. Now, instead of dragging that conversation forward, you're giving a new agent a fresh start to solve the problem. This is especially useful if you want to step away for a few hours or Claude keeps trying the same solution that doesn't work over and over again.
