 Ultracode is an insane new feature inside of Cloud Code, and here's how you can start using it right away. So to get access to Ultracode, all you have to do is bring up Cloud Code, do forward slash effort, and then tab over to Ultracode. Once you have Ultracode selected, you are now going to be in extra high effort mode and you get access to dynamic workflows. Dynamic workflows let Cloud Code better handle complex tasks. They spawn up to 100 plus agents all at the same time. And while they are token heavy, they are best for these really difficult problems. I did a whole deep dive on this feature and dynamic workflows on my YouTube, so make sure you check that out if you want to learn more.
