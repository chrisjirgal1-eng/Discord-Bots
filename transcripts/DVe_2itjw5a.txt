 Do not leave your API key exposed on OpenClaw. Do not be like these guys and lose $82,000 in just 48 hours from a stolen Gemini API key. Having someone else's API key is just like getting a blank check. They not only lost the money, but are also facing bankruptcy from their company. If you're running OpenClaw, you likely have API keys sitting in the config files for every service that you use. Do not store API keys in plain config files. Instead, use environment variables or a secret manager like Mac OS Keychain. OpenClaw supports this natively with SecretRef. Do not leave API billing caps open. Instead, set hard caps for all of your API keys. Not run OpenClaw on Docker with network access. Set it to run on restricted network access so that even if your OpenClaw does get compromised, the blast radius stays within the container. And that way it can't reach your other files.
