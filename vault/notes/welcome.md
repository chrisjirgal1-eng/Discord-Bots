# Welcome to Zoe's memory

This is a curated note (committed to git). Sessions, the command log, and the index are generated
at runtime and stay out of git.

Zoe and Claude both read and write here. Examples:
- Ask Zoe (voice or command bar): *"what did I say last session"* -> she reads [[index]] and the latest session.
- Save a thought: `python tools/zoe_memory.py write "Idea name"` then edit the note.
- Link notes with `[[wikilinks]]`, like [[welcome]] linking back here.

See [[../README|the vault README]] for the full API.
