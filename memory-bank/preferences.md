# Preferences

How Chris likes to work and be communicated with.

## Communication

- Wants outcomes, not lectures. Act when you have enough to act.
- Give a recommendation, not an exhaustive survey of options.
- Short lines. One idea per line. Specific numbers.
- When writing posts, threads, or captions: 3 versions, label the strongest and why.

## Build style

- Prefers building practical systems over working through theory first.
- Likes incremental builds he can start using right away.
- Started on no-code and low-code Discord tooling, now moving toward custom code and MCP.

## Voice for outreach and content

- Natural, non-AI-sounding voice. Avoid the tells: "delve", "leverage", "fantastic", em dashes.
- For coach outreach emails: natural, human, competitive, not robotic.

## Tools and budget

- Strong preference for free and low-cost tool stacks (Calendly, Beacons.ai, PayPal, Zelle).
- Explored running Claude Code locally for free via Ollama (Gemma 3 12B).
