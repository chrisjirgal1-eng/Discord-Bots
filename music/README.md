# ZOE background music

Drop one epic track in this folder and ZOE uses it automatically for the cinematic
capabilities rundown. No `.env` editing needed.

- Any `.mp3`, `.m4a`, `.wav`, `.ogg`, or `.flac` works. She picks the first one here.
- Prefer a specific file instead? Set `ZOE_MUSIC=full\path\to\track.mp3` in `.env` (that wins).
- Too loud / too quiet under her voice? Set `ZOE_MUSIC_GAIN` in `.env` (default `0.25`).

## Free, genuinely epic tracks (Avengers energy, no copyright strike)

Grab one, drop it here, done. You pick by ear since "epic" is your call:

- **Scott Buckley** (scottbuckley.com.au): cinematic orchestral, CC-BY. Try *Sovereign*,
  *Undertow*, or *Permafrost*. The most Avengers-tier of these.
- **Pixabay Music** (pixabay.com/music): search "epic cinematic". Pixabay license, no
  attribution, one-click download.
- **Kevin MacLeod** (incompetech.com): CC-BY. Try *Heroic Age* or *Hero Theme*.

If you use a CC-BY track (Scott Buckley, Kevin MacLeod), keep the artist credit somewhere;
Pixabay needs no attribution. No copyrighted audio (the actual Avengers score) goes in this repo.

Real audio files are gitignored here so the repo stays light. The track lives on your machine.
